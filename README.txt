- หน้าแรกเว็บไซต์แฟ้มผลงานการสอน ก่อนเข้าสู่ E-book
- ใช้ชื่อ ครูกฤษฎา ผิวขำ
- เพิ่มภาพบุคลากรจากภาพที่ผู้ใช้แนบมา

- มีเมนู เกี่ยวกับฉัน / ผลงานการสอน / E-book / เอกสารประกอบ / ติดต่อ
- มีปุ่มกลับหน้าแรกจากหน้า E-book
- รองรับคอมพิวเตอร์ แท็บเล็ต และมือถือ

การนำขึ้น GitHub Pages
1. แตก ZIP
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดเข้า repository
3. ให้ index.html อยู่ที่ระดับรากของ repository
4. GitHub Pages ใช้ branch main และ folder / (root)
5. เปิดเว็บไซต์จาก URL ของ GitHub Pages ของ repository

หมายเหตุ: ไฟล์นี้เป็นเว็บไซต์แบบ static ไม่ต้องติดตั้งเซิร์ฟเวอร์เพิ่มเติม
